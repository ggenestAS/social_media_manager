# albert-prep-agent post types

The organic menu, derived from the creatives produced in the Claude Design
import (2026-09-20) so organic and paid share one visual world:

| Type | Format | Mechanic |
|---|---|---|
| [`statement/`](statement/) | 4:5 (+ 9:16 story adapt), 1 board | Black frame, one sentence, the cursor |
| [`press-split/`](press-split/) | 4:5 (+ 9:16), 1 board | Press headline on paper / Albert's reply on ink |
| [`carousel/`](carousel/) | 4:5 × 4 cards | Clippings hook → the wrong AI → the plan card → light CTA card |
| [`press-reel/`](press-reel/) | 9:16 animated, ~13 s | Headline builds → the reply slams up → the hero line → CTA |

Each folder: `spec.md` (rules) + `template.html` (a real, rendered asset to
copy from). `press-reel/reel-timeline.js` is the animation engine every reel
bundle inlines. Add a type only by graduating a winning experiment.
